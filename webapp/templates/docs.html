🛠️ Technology Stack

This application leverages the **CRISP-DM** methodology for data mining.

  • Algorithm: Random Forest Classifier (Scikit-Learn)
  • Backend: Flask (Python 3.9) with Gunicorn
  • Processing: Pandas, NumPy, SMOTE (Synthetic Minority Over-sampling Technique)
  • Frontend: HTML5, Tailwind CSS, Alpine.js logic
  • Visualization: ApexCharts.js for radar analysis

✨ Key Features

1. Real-time Prediction Engine

Input weather parameters (Humidity, Sunshine, Wind, etc.) to get an instant probability score of rainfall for the next day.

2. Historical Backtesting

Validate the model's accuracy by testing it against real historical data from 2008-2017. Select a location and test random dates to see the "Model vs Actual" performance.

3. Explainable AI (XAI)

The system doesn't just guess; it explains WHY. The "Key Factors" section highlights which parameters (e.g., high humidity or low pressure) contributed most to the prediction.
